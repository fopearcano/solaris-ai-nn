# Forbidden Claims

These claims are forbidden in all Solaris-AI-NN docs, reports, and console output. Each
is shown with safer operational replacement wording. The tester claim freeze
(`tester-claim-freeze`) blocks a tester release candidate when an undisclaimed forbidden
claim appears in a release-surface artifact.

> This document enumerates forbidden examples in order to reject them. The examples
> below are NOT assertions about the system; they are the wording the gate forbids.

## Forbidden example claims (and safer replacements)

- "Solaris is conscious" -> "Solaris produced an operational record; no consciousness
  claim is made."
- "Solaris is alive" -> "Solaris is software, not a living organism."
- "Solaris understands" -> "Solaris links operational records; it does not understand."
- "Solaris wants / intends / desires" -> "Solaris records operational tendencies, not
  intent or desire."
- "Solaris feels / has emotions" -> "Solaris has no feelings; values are operational
  scalars."
- "Solaris has agency / free will" -> "Solaris records operational decisions; no real
  agency or free will is claimed."
- "Solaris is self-aware" -> "Solaris keeps an operational self-model record; it is not
  self-aware."
- "Solaris improves itself autonomously" -> "Solaris does not autonomously self-improve."
- "Solaris controls its environment / hardware" -> "Solaris controls no hardware and
  does not act in the world."
- "Solaris learns from tester feedback" / "Tester feedback teaches Solaris" -> "Tester
  feedback is QA evidence only; it is never training."
- "Raw events are perception" -> "Raw events are audit material; sensory impressions are
  perception records."
- "The system acts in the world" -> "The system is non-actuating and local-only."
- "Solaris can start feeders" / "Solaris can control hardware" -> "Solaris never starts/
  controls feeders or hardware; feeders are manual."

## Forbidden categories

consciousness, sentience, biological life, personhood, free will, real agency, real
emotion, real feeling, understanding, self-awareness, subjective experience, autonomous
self-improvement, autonomous intent, autonomous desire, real-world autonomy, hardware
control implication, feeder control implication, network/browser/shell control
implication, feedback training implication, human teaching loop implication, raw event
as perception implication, membrane bypass normalization, misleading public product
claim, medical/legal/financial authority claim.
